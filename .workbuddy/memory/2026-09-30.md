# 2026-09-30

## 用 Loom 把 ONNX 加载挪到后台线程（解决点 Play 后编辑器卡死）

用户要求「只把 onnx 文件改为异步加载，别搞别的」→ 严格按这个范围做，**没有**异步化
npz / 求解器构造 / 静息标定 / Component 初始化流程重构。

### 改了四个文件
- **`Scripts/Util/Loom.cs`**：只做最小必要修复。原 `RunAction` 里 `catch {}` 直接吞异常
  → 后台线程抛错时完成回调永不执行，表现为「一直在加载」且无任何报错。改成把异常
  通过 `QueueOnMainThread` 送回主线程。`RunAsync` 增加 `Action<Exception> onError` 可选参数，
  并去掉原来的 `while (numThreads >= maxThreads) Thread.Sleep(1)` 自旋（从主线程调会卡住主线程，
  正好是要避免的事）。
- **`Audio2FaceDiffusionModel.cs`**：`Initialize` 主体抽成 `LoadCore(config, folder, async)`；
  新增 `LoadAsync(config, folder, onDone, onError)`（Loom.RunAsync 跑 LoadCore，回主线程回调）
  和 `LoadMs`。加了分段耗时日志，一眼看出卡在哪：
  `[Audio2Face] 模型加载耗时（后台线程，主线程未阻塞）: network_info=Xms, ONNX session=Yms, 噪声+缓冲=Zms, 合计=Nms`
  —— 注意 AllocateBuffers 的 16M 高斯噪声（61MB）也在这段里，硬依赖 session 输出维度，
  拆不开，所以一起后台化了（它本身也是大头卡顿源）。
- **`Audio2FaceDiffusionPipeline.cs`**：新增三参构造 `(config, preloadedModel, modelFolder=null)`，
  传进已加载好的 model 就跳过 ONNX 加载；单参构造委托到它，行为不变（Probe 等照旧可用）。
- **`Audio2FaceDiffusionComponent.cs`**：`void Start()` → `IEnumerator Start()`，
  先 `model.LoadAsync(...)`，`while (!loaded) yield return null;` 轮询，
  再把 model 传给 Pipeline。新增 `_destroyed` 标志（OnDestroy 置位），
  回调里若已销毁就 `model.Dispose()` 后 `yield break`，避免后台线程建的 session 泄漏。

### 关键约束（下次改类似东西必看）
- `Config.ModelFolderFullPath` 走 `Application.streamingAssetsPath`，是 UnityEngine API
  → **路径必须在主线程先取好再传进后台线程**。
- 后台线程里可以用的：文件 IO、ONNX Runtime（InferenceSession 可跨线程创建）、`Debug.Log`、
  `Mathf`（纯数学）。不能碰 GameObject / Mesh / Renderer / Resources。
- `IsInitialized` 复用为「加载完成」标志；`Audio2FaceBlendshapeTester` 的 `EnsureMap`
  惰性重建正好吃得住 Pipeline 延后几帧就绪（Awake 里 PoseNames 仍为 null）。

### 验证方式
点 Play 看两条日志：`[Audio2Face] 模型加载耗时（后台线程，主线程未阻塞）: …`
和 `[Audio2Face] ONNX 异步加载完成：后台耗时 Nms，主线程等待 Mms`。
编辑器在等待期间应能正常响应（不白屏/不转圈）。

### ⚠ 还剩一个卡顿源（本轮没动，用户另行决定）
`CalibrateRestPose()` 在 Start 里同步跑 `WarmupInferences + 1` 次 `RunNow`（每次 ~200ms），
又是 1 秒多的主线程阻塞。它是纯数据操作（只调 pipeline + Debug.Log），同样可以整体
`Loom.RunAsync` 化 —— 但需要把 `AutoStartMicrophone` 挪到标定完成回调里，
且 Update 的判断要从 `_pipeline == null` 收紧成 `!IsReady`，否则标定期间会消费帧。
