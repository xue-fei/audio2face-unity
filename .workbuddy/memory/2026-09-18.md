# 2026-09-18

## Audio2Emotion Unity 推理管线

在 audio2face-unity 项目中实现了完整的 Audio2Emotion v2.2 ONNX 推理管线。

### 文件清单

- `Assets/Scripts/Audio2Emotion/Audio2EmotionConfig.cs` - 模型配置（采样率、路径、后处理参数）
- `Assets/Scripts/Audio2Emotion/Audio2EmotionResult.cs` - 推理结果结构（原始概率 + 处理后权重）
- `Assets/Scripts/Audio2Emotion/Audio2EmotionSession.cs` - ONNX Runtime 推理会话（支持 CUDA/CPU）
- `Assets/Scripts/Audio2Emotion/Audio2EmotionPostProcessor.cs` - 后处理（对比度、平滑、偏好情绪）
- `Assets/Scripts/Audio2Emotion/Audio2EmotionManager.cs` - 管理器（流式/块推理接口）
- `Assets/Scripts/Audio2Emotion/Audio2EmotionComponent.cs` - Unity MonoBehaviour 组件
- `Assets/Scripts/Audio2Emotion/Audio2EmotionExample.cs` - 使用示例（测试音频/麦克风）
- `Assets/Scripts/Audio2Emotion/Audio2Emotion.asmdef` - 程序集定义

### 关键信息

- 模型路径: `Assets/StreamingAssets/Audio2Emotion-v2.2/network.onnx`
- 模型架构: Wav2Vec2-Large-LV60, 3.1亿参数
- 输入: 16kHz PCM float32, 形状 [1, window_size]
- 输出: 6种情绪概率 [angry, disgust, fear, happy, neutral, sad]
- 使用 onnxruntime-unity 包（CPU + CUDA 均支持）
- 后处理：对比度增强 → 历史平滑 → 实时混合 → 偏好情绪 → 强度缩放

## Audio2Emotion 后处理器修复（对齐 SDK）

- 删除 `network.onnx.meta` 修复 Import Error Code:(5)（大小写不一致导致 SourceAssetDB 找不到资源）
- 参考 Audio2Face-3D-SDK `postprocess.cpp` 重写 `Audio2EmotionPostProcessor.cs`
- 旧实现 5 个关键错误：
  1. Min-Max 归一化代替 softmax（logits 当概率处理）
  2. 历史缓冲区存 raw logits 而非 softmax 后的概率
  3. 在 6 维空间做时序混合（应在 10 维 blendshape 空间）
  4. transitionSmoothing 用固定系数 0.5 而非 dt/transitionTime
  5. 首帧无特殊处理（SDK 首帧用 beginningEmotion 初始化）
- 新实现严格对齐 SDK 8 步流程：EmotionContrast → NullifyUnmapped → MaxEmotions → IndexConversion → Blending → PreferredEmotion → TransitionSmoothing → EmotionStrength
- 修复后 FinalOutput 应全部在 [0, 1] 范围内

## Audio2Face v3.0 口型同步调试

通过分析 SDK C++ 源码确认正确参数并修复 Unity 管线。

### SDK 核心公式（executor_diffusion_core.cpp）
```
strideNum = bufferLength * numFramesCenter = 16000 * 30 = 480000
strideDenom = nbFramesPerInference = 60
stride = 8000 (0.5 秒)
frameRate = 60 * 16000 / 16000 = 60 fps
```

### 修复内容

1. **StrideSamples 恢复为 8000**（之前误改为 16000）
   - 正确公式：`BufferLength * FramesCenter / FramesPerInference`

2. **预热同步**（真正的 bug）
   - 问题：音频推流即播放，但模型需要 2 次预热推理（~1秒），导致音频比动画快
   - 修复：3 阶段推流（推预热音频 → 等预热完成 → 播放音频并跳过预热部分）

3. 背压注释修正

## 关键修复：SkinMultOverrides 错误 multiplier（口型不正常的根因）

对比官方 `Audio2Face-3D-Samples/configs/*_diffusion_stylization_config.yaml`：
- `weight_multipliers` **全部是 1.0**
- `weight_offsets` **全部是 0.0**
- 与 SDK 库层 `bs_skin_config_*.json` 的 `bsWeightMultipliers`（全 1.0）完全一致。

但 Unity `BlendshapeSolver.cs` 里之前硬编码了一整套非 1.0 的 multiplier：
- mouthClose=0.3（把闭嘴压到 30%）
- jawForward=0.7、jawLeft/Right=0.2、mouthLeft/Right=0.2
- mouthStretch=0.05（嘴角横向拉伸几乎关掉）
- cheekPuff=0.2 等

这套值声称来自「微服务文档」，但与官方 Samples 仓库 yaml 完全矛盾，是口型不正常的直接根因。
**修复**：清空 `SkinMultOverrides`/`SkinOffsetOverrides`/`TongueMultOverrides`/`TongueOffsetOverrides`，让 multiplier 严格按官方 1.0 走。

### 保留正确项
- `SkinActiveOverrides`（jawLeft/jawRight/mouthLeft/mouthRight = active）—— 这是对的：json 里 active=0，官方 yaml 里 active=1，必须激活否则「嘴歪眼斜」。
