## 修「牙齿没跟着动」+ Inspector NRE（2026-10-10 续）

- 根因：mark_arkit_v3 的牙齿是**挂在下颌骨骼上**的（A2F 只把 jawOpen 当 blendshape 驱动嘴唇皮肤，下颌刚体变换必须落到骨骼）。`JawBone` 字段之前没填 → 下颌不转 → 牙齿冻着、嘴皮子在动。组件注释/警告早就写了这点（`[A2F骨骼] 没填 Jaw Bone —— 挂在骨骼上的牙齿不会动`）。
- 修复：`Start()` 里新增 `AutoDetectBones()`（在 ModelPrefab 实例化之后、JawBone 警告之前调用）。按名字在 `_modelInstance`（没设则 `transform`）下找含 jaw/lowerjaw/lower_jaw 的 Transform，找到就填进 `JawBone`（手填过则跳过，不覆盖）。`FindBoneByName` 用名字长度当近似打分取最短（偏向纯骨骼名 "Jaw"）。日志 `[A2F骨骼] 自动找到下颌骨：<name>（<path>）`。
- 配套：NRE 是 Unity 2021.3 在 Inspector 重绘 `float[]` 时 UIElements ListView（`SerializedObjectList.get_Count`）对失效 SerializedObject 抛空引用，**不影响运行时**。给 `ManualEmotion`(A2F 组件) 和 A2E 的 `preferredEmotion` 都加 `[NonReorderable]`，关掉虚拟列表渲染，消掉 NRE。

## 修「讲话时下牙齿没跟着下巴动」（2026-10-10 续·合成下颌支点）

- 根因再确认：不是绑定问题（c_bottomDenture_hi 的 jawOpen 早已映射并写入），而是 frame 布局 `skin(52)+tongue(16)+jaw(7)+eyes(4)` 里 **jaw 通道（旋转角+轴+下颌质心位移，JawChannelOffset=68）整段被丢弃**——因为 mark_arkit_v3 是单骨 rig（只有 joint1），`AutoDetectBones` 找不到独立下颌骨 → `JawBone==null` → `ApplyFrame` 里 `if (JawBone != null)` 不成立，jaw 通道不作用。结果头模靠 jawOpen blendshape 把嘴唇皮张开（看着嘴在动），但牙齿只拿到 jawOpen（只动嘴唇皮），**没有刚体平移/旋转把整排牙带下去** → "牙冻着"。
- 佐证：pipeline 注释 `下颌/牙齿：jaw 段 → 刚体变换。牙齿挂在骨骼上，只有这一步能让它动`（Audio2FaceDiffusionPipeline.cs:30/323/811）；且旧日志 `jaw animator 已启用: 标记点=5` 说明 SDK 的刚性下颌通道**确实在有值产出**，只是没地方接。
- 修复：新增 `EnsureSyntheticJawPivot()`，在 `AutoDetectBones` 的 else 分支调用。单骨 rig 时造一个合成 `JawPivot`（GameObject，挂到 _modelInstance 下），支点放在下牙质心（world bounds.center）使旋转≈绕铰链张合；把 **c_bottomDenture_hi（牙齿）+ c_tongue_hi（舌头）** 用 `SetParent(pivot, worldPositionStays:true)` 挂上去（保持世界位姿不瞬移），再设 `JawBone = pivot`。之后 `ApplyFrame` 自动把 jaw 刚体通道作用到支点上，牙齿+舌头随下巴刚体运动——符合 A2F 原意。
- 网格匹配：优先精确名 `c_tongue_hi` / `c_bottomDenture_hi`，退化到含 tongue/denture（排除 top/upper）关键字，避免误挂。blendshape 来源不变：牙齿 blendshape 仍从 c_bottomDenture_hi 取、舌头 blendshape 仍只从 c_tongue_hi 取（dedicatedTongue 逻辑）。
- 绑定顺序无关：绑定收集循环（Start 内、模型加载 await 后）用 `GetComponentsInChildren` 仍能拿到被重挂的这两个网格；`IsTongueMesh` 按名识别 c_tongue_hi → 舌头权重仍只下发给它。
- 可调项：JawRotationAxis / JawAngleSign / JawAngleGain(默认3) / JawTranslationScale(默认0.01) 是 Inspector 旋钮，首跑若开合方向/幅度不对再调。
